# Build: python-pptx, Registry, Charts, Checks

Every authored deck on this machine is python-pptx on the blank layout with every element placed by inch coordinates, generated by one script. No template inheritance, no pptxgenjs, no Marp, no reveal.js, no Keynote. Google Slides is a distribution target, reached by importing the `.pptx`.

## The Script Is the Deck

- `build_deck.py` (or `build_<name>_deck.py`) regenerates everything in one command, in seconds, with no network: clears the chart folder, regenerates every chart and diagram as SVG and PNG, builds the `.pptx` from a declarative list of slide builders. Page numbers derive from the list length; reorder slides by moving lines.
- "Edits made in PowerPoint are lost on the next rebuild. To change a number, edit `figures.csv`. To change wording, edit the build script."
- Rebuild rather than slide surgery. Editing shape indices in an existing `.pptx` "would be fragile in a way nobody could check." The one exception: inserting a single slide into a colleague's deck whose source you do not own (renumber pages afterwards).
- When patch-on-patch degrades a deck, rebuild from scratch off the raw data with the old deck as the structural reference.
- Scripts live in the project folder, never the session scratchpad. The methodology deck's script still points at a dead scratchpad path and cannot be rerun.

## Primitives

`scripts/deck_primitives.py` carries the house idiom: 16:9 (13.333 x 7.5 in), blank layout 6, eyebrow over a plain-noun title, numbered points with a bold lead-in, tinted stat tiles, native tables with an accent header row, one takeaway line ruled off above the footnote, slide number in the corner, speaker notes. Import it or the family's own primitives module:

```python
import sys; sys.path.insert(0, str(Path.home() / ".claude/skills/deck/scripts"))
from deck_primitives import *
use_palette(PALETTE_FIELD)          # or PALETTE_CORPORATE for board decks
load_registry(HERE / "analysis" / "figures.csv")
```

Geometry constants: `L, W = 0.6, 12.1`, `HEAD_T 0.42`, `BODY_T 1.72`, `TAKE_T 6.42`, `FOOT_T 6.62`. Anything crossing the footnote rule at 6.48 in collides with the footnote.

Native text boxes and native tables for anything text-shaped. Images only for flowcharts, architecture and charts with axes; raster text leaks stale names and typos that nobody re-renders.

## Palettes

Two coexist. Pick by deck family, single-source the hex codes as constants at the top of the script (mirrored in a `brand.md` if the deck has one), never mix.

| Role | Field family (technical and workshop decks) | corporate example (board, exec, partner) |
|---|---|---|
| Accent, hero, table header | `#2F6B3A` green | `#1CA069` brand green |
| Second accent, eyebrow, numerals | `#A86518` ochre | `#4EBB95` brand secondary (vendor, external) |
| Ink | `#15180F` | `#313131` |
| Muted | `#585D4E` | `#8A8A8A` |
| Tint surface | `#F3F5EC` | `#F8F9FA` |
| Rule | `#D8DDC8` | `#E5E7EB` |
| Warning, open | `#9C3B2E` | `#E07A2B` caution orange |
| Emphasis block | ochre bar | `#32373C` charcoal |
| Font | Arial | Calibri or Helvetica |

Status colours reused deck-wide: accent = done or shipped, second accent = vendor or external, warning = in progress or open, muted = not applicable. No purples, blues or magentas outside the palette. Where a deck compares channels, the modality tokens are green for image or photo, grey for text, near-black grey for voice; a deck without that split uses the accent and neutrals.

Typography (DG): title 36 to 44 pt, subtitle 20 to 24 pt, body 18 to 22 pt, footnote 11 to 14 pt. Field family: title 28 pt under a 12.5 pt eyebrow, body 15 pt, footnote 11 pt. Minimum chart text equivalent to 14 pt at projection.

## Figures Registry

`analysis/figures.csv` columns: `key, slide, claim, value, row_set, source, status`.

- `status` is `measured` (reproducible from a script here), `quoted` (external report, not independently checked), `assumed` (a modelling input), `pending` (being computed) or `blocked` (waiting on a person).
- The build types no figures. Every one is `fig("key")`; an unknown key raises. Pending and blocked rows render as a visible pending block naming the owner.
- Never quote a figure without its `row_set`. Several numbers are true on more than one row set and differ between them.
- The build reports registry rows no slide quotes: a lost number or a row to retire.
- Each analysis script writes its own CSV and a markdown report; read the report, not the CSV. Keep raw extracts in a durable project subfolder, never only in scratch.

## Charts and Diagrams

- Charts: matplotlib, reading the CSV the registry cites so the chart re-renders when data changes. Save SVG (real text, re-readable by Claude later) and PNG (300 DPI for embedding; downscale with `downscale()` to about 1300 px wide before embedding so the deck stays small).
- Font stack for matplotlib with Indic fallback: `DejaVu Sans, Helvetica, Arial, Devanagari MT, Telugu Sangam MN, Kannada MN, Kohinoor Devanagari, Kohinoor Telugu`. DejaVu first so arrows do not render as tofu.
- Diagrams: Graphviz DOT rendered by `dot -Tsvg` and `dot -Tpng -Gdpi=170`. Keep the `.dot` beside its outputs. Horizontal orientation, sized to the slide, every label fits its box. Diagrams carry structure only, no measurements, and no title (the slide header is the title). Never Mermaid.
- No number baked into an image. `charts/_retired/` exists for charts that broke this rule.
- 16:9 aspect for full-width charts; side by side beats stacked.

See `references/figures.md` for which chart form to use.

## Checks

Run after every build, before every hand-over:

```bash
S=~/.claude/skills/deck/scripts
python3 $S/check_layout.py  <deck>.pptx                        # overlaps, overfull text, footnote collisions
python3 $S/check_figures.py --deck <deck>.pptx --registry analysis/figures.csv [--charts charts/] [--exempt "MyModel-\d+B"]
python3 $S/check_words.py   <deck>.pptx --names names.txt      # titles, em-dashes, jargon, codes, names; add --no-notes for internal decks
python3 $S/preview_slides.py <deck>.pptx                       # approximate PNG per slide; read them with the Read tool
python3 -c "from pptx import Presentation as P; p=P('<deck>.pptx'); print(len(p.slides),'slides', sum(1 for s in p.slides for sh in s.shapes if sh.shape_type==13),'images')"
open <deck>.pptx
```

- `check_layout.py` approximates a renderer: treat a warning as "open this slide and look". Tables are the main risk; a wrapping cell grows the table into the footnote.
- `check_figures.py` exits 1 on any numeral that resolves to no registry row. It reports rows no slide quotes and numerals carried by generated diagrams as separate categories. It is an existence check, not a semantics check.
- `check_words.py` exits 1 on any hit. Expected clean on slides; speaker notes of internal decks may legitimately carry codes.
- `preview_slides.py` draws every slide from the shape tree (no PowerPoint or LibreOffice on the machine). Read the PNGs: blank slides, overlaps, pictures off the page and text past the box edge all show. Wrapping is estimated, so a clipped line means look at that slide in the real file.
- Record the expected baseline in the rules file ("33 slides, 27 embedded images, ~2.7 MB") so a drift is visible.
- Export to PDF and open it; multi-column rows that reflow into stacks are a defect.
- Verify each previously raised defect individually before saying it is fixed.

## Pitfalls

| Symptom | Cause | Fix |
|---|---|---|
| Arrow renders as a box in a chart | Helvetica lacks U+2192 | DejaVu Sans first in the font stack |
| `[graphviz] failed to render` | `dot` missing | `brew install graphviz` |
| Images missing in the deck | relative path | absolute `CH / "name.png"`, never bare strings |
| Divider text invisible | ink colour on a green background | white text on accent or charcoal full-bleed slides |
| Page numbers stale | hardcoded | derive from `len(builders)` after the list is built |
| Table sits on the footnote | wrapping cell grew the row | shorten text, widen the column, or raise the table |
| Deck is 4 MB+ | 300 DPI PNGs embedded raw | `downscale()` to about 1300 px |
| Slides blank after a restructure | build error swallowed | check the script exits 0, open the file |
