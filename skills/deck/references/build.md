# Build

Applies to: the build script, the primitives, palettes and typography, the figures registry, chart and diagram generation, the gate scripts, and common build failures.

Every deck built with this skill is python-pptx on the blank layout, with every element placed by inch coordinates and generated by one script. No template inheritance, no pptxgenjs, no Marp, no reveal.js, no Keynote. Google Slides is a distribution target, reached by importing the `.pptx`.

`<skill-dir>` below is wherever the skill is installed (for example `~/.claude/skills/deck`). Build scripts read it from the `DECK_SKILL_DIR` environment variable; `deck_primitives.SKILL_DIR` resolves it from the module's own location.

## The Script Is the Deck

- `build_deck.py` (or `build_<name>_deck.py`) regenerates everything in one command, in seconds, with no network: clears the chart folder, regenerates every chart and diagram as SVG and PNG, builds the `.pptx` from a declarative list of slide builders. Page numbers derive from the list length; reorder slides by moving lines.
- Edits made in PowerPoint are lost on the next rebuild. To change a number, edit `figures.csv`. To change wording, edit the build script.
- Rebuild rather than slide surgery. *Why: editing shape indices in an existing `.pptx` is fragile in a way nobody can check.* The one exception: inserting a single slide into a colleague's deck whose source you do not own (renumber pages afterwards).
- When patch-on-patch degrades a deck, rebuild from scratch off the raw data with the old deck as the structural reference.
- Scripts live in the project folder, never the session scratchpad. *Why: a build script pointing at a deleted scratch path can never be rerun.*

## Primitives

`scripts/deck_primitives.py` carries the house idiom: 16:9 (13.333 x 7.5 in), blank layout 6, eyebrow over a plain-noun title, numbered points with a bold lead-in, tinted stat tiles, native tables with an accent header row, one takeaway line ruled off above the footnote, slide number in the corner, speaker notes. Import it or the family's own primitives module:

```python
import os, sys
from pathlib import Path
SKILL_DIR = Path(os.environ.get("DECK_SKILL_DIR", "~/.claude/skills/deck")).expanduser()
sys.path.insert(0, str(SKILL_DIR / "scripts"))   # a real path: "~" is not expanded on sys.path
from deck_primitives import *
use_palette(PALETTE_FIELD)          # or PALETTE_CORPORATE, or your own brand dict
load_registry(HERE / "analysis" / "figures.csv")
```

Geometry constants: `L, W = 0.6, 12.1`, `HEAD_T 0.42`, `BODY_T 1.72`, `TAKE_T 6.42`, `FOOT_T 6.62`. Anything crossing the footnote rule at 6.48 in collides with the footnote.

Native text boxes and native tables for anything text-shaped. Images only for flowcharts, architecture and charts with axes. *Why: raster text cannot be edited or scrubbed, and leaks stale names and typos that nobody re-renders.*

## Palettes

This is the one home for palette values; `figures.md` points here. Pick by deck family, single-source the hex codes as constants at the top of the script (mirrored in a `brand.md` if the deck has one), and never mix.

| Role | `PALETTE_FIELD` (technical and workshop decks) | `PALETTE_CORPORATE` (example; replace with your brand) |
|---|---|---|
| Accent, hero, table header | `#2F6B3A` green | `#1F4E79` navy |
| Second accent, eyebrow, numerals | `#A86518` ochre | `#B4510F` burnt orange (vendor, external) |
| Ink | `#15180F` | `#1A1A1A` |
| Muted | `#585D4E` | `#5F6368` |
| Tint surface | `#F3F5EC` | `#F4F6F8` |
| Rule | `#D8DDC8` | `#D9DDE3` |
| Warning, open | `#9C3B2E` | `#A4262C` |
| Emphasis block | ochre bar | `#2E3338` charcoal |
| Font | Arial | Calibri |

`PALETTE_CORPORATE` is an accessible example: white text passes WCAG AA on the accent (8.7:1), second accent (5.1:1), warning (7.3:1) and charcoal, and the dark navy accent and mid-tone orange second accent stay distinct in greyscale. Status pills always carry a text label, never colour alone, because warning and accent are close in lightness. To use your brand, copy the dict, change the values, and pass it to `use_palette()`.

Status colours reused deck-wide: accent = done or shipped, second accent = vendor or external, warning = in progress or open, muted = not applicable. No colours outside the palette.

Fixed colour per category: where a deck splits data by category (channel, data type, region), give each category one colour and reuse it on every chart and table in the set. For example, a deck comparing input channels might use the accent for images, grey for text and near-black grey for voice. A deck without such a split uses the accent and neutrals.

Typography (corporate): title 36 to 44 pt, subtitle 20 to 24 pt, body 18 to 22 pt, footnote 11 to 14 pt. Field family: title 28 pt under a 12.5 pt eyebrow, body 15 pt, footnote 11 pt. Minimum chart text equivalent to 14 pt at projection.

## Figures Registry

`analysis/figures.csv` columns: `key, slide, claim, value, row_set, source, status`.

- `status` is `measured` (reproducible from a script here), `quoted` (external report, not independently checked), `assumed` (a modelling input), `pending` (being computed) or `blocked` (waiting on a person).
- The build types no figures. Every one is `fig("key")`; an unknown key raises. Pending and blocked rows render as a visible pending block naming the owner.
- Derived values (ratios, percentage changes, roundings, a monthly figure from an annual one) get their own registry row, with the formula and its input keys in `claim`. *Why: a number computed in the build script or typed as a rounding never updates when its inputs change, and the figures gate cannot trace it.* Example: `cost_month` with claim `= cost_year / 12`.
- Never quote a figure without its `row_set`. Several numbers are true on more than one row set and differ between them.
- The build reports registry rows no slide quotes: a lost number or a row to retire.
- Each analysis script writes its own CSV and a markdown report; read the report, not the CSV. Keep raw extracts in a durable project subfolder, never only in scratch.

## Charts and Diagrams

- Charts: matplotlib, reading the CSV the registry cites so the chart re-renders when data changes. Save SVG (real text, re-readable later) and PNG (300 DPI for embedding; downscale with `downscale()` to about 1300 px wide before embedding so the deck stays small).
- Font stack for matplotlib: `DejaVu Sans, Helvetica, Arial`, DejaVu first so arrows and symbols do not render as empty boxes. If the deck shows non-Latin scripts, append a font for each script installed on the machine (check with `fc-list :lang=<code>`) after DejaVu, and render one test label per script before building the set.
- Diagrams: Graphviz DOT rendered by `dot -Tsvg` and `dot -Tpng -Gdpi=170`. Keep the `.dot` beside its outputs. Horizontal orientation, sized to the slide, every label fits its box. Diagrams carry structure only, no measurements, and no title (the slide header is the title). Never Mermaid.
- No number baked into an image. `charts/_retired/` holds charts that broke this rule.
- 16:9 aspect for full-width charts; side by side beats stacked.

See `figures.md` for which chart form to use.

## Checks

Run after every build, before every hand-over:

```bash
S=<skill-dir>/scripts
python3 $S/check_layout.py  <deck>.pptx                        # overlaps, overfull text, footnote collisions
python3 $S/check_figures.py --deck <deck>.pptx --registry analysis/figures.csv [--charts charts/] [--exempt "MyModel-\d+B"] [--exempt-file exempt.txt]
python3 $S/check_words.py   <deck>.pptx --names names.txt      # add --external for decks that leave the organisation, --no-notes to skip notes
python3 $S/preview_slides.py <deck>.pptx                       # approximate PNG per slide; read them
python3 -c "from pptx import Presentation as P; p=P('<deck>.pptx'); print(len(p.slides),'slides', sum(1 for s in p.slides for sh in s.shapes if sh.shape_type==13),'images')"
open <deck>.pptx
```

- `check_layout.py` approximates a renderer: treat a warning as "open this slide and look". Tables are the main risk; a wrapping cell grows the table into the footnote.
- `check_figures.py` exits 1 on any numeral that resolves to no registry row. It reports rows no slide quotes and numerals carried by generated diagrams as separate categories. It checks existence, not meaning. Project model names and stage labels with digits go in `--exempt` or `--exempt-file`.
- `check_words.py` exits 1 on any hit. Built-in checks: em-dashes, AI-tell and hype phrases, title shape. House lists (jargon, banned slide words, invented metric words, internal codes) load from `scripts/house_words.json`; pass `--words <file>` for a project copy and `--codes REGEX` for extra code patterns. Expected clean on slides; speaker notes of internal decks may carry codes unless `--external` is set.
- `preview_slides.py` draws every slide from the shape tree, for use when no PowerPoint or LibreOffice renderer is available. Read the PNGs: blank slides, overlaps, pictures off the page and text past the box edge all show. Wrapping is estimated, so a clipped line means look at that slide in the real file.
- Record the expected baseline in the rules file (for example "33 slides, 27 embedded images, ~2.7 MB") so a drift is visible.
- Export to PDF and open it; multi-column rows that reflow into stacks are a defect.
- Re-verify each previously raised defect individually (`review.md` §Working Agreements, item 8).

## Pitfalls

| Symptom | Cause | Fix |
|---|---|---|
| Arrow renders as a box in a chart | Helvetica lacks U+2192 | DejaVu Sans first in the font stack |
| Non-Latin labels render as boxes | No font for that script in the stack | Append an installed font for the script after DejaVu |
| `[graphviz] failed to render` | `dot` missing | Install Graphviz (`brew install graphviz` on macOS) |
| `ModuleNotFoundError: deck_primitives` | `sys.path` given a literal `~` path | Expand the path (`Path(...).expanduser()`) or set `DECK_SKILL_DIR` |
| Images missing in the deck | Relative path | Absolute `CH / "name.png"`, never bare strings |
| Divider text invisible | Ink colour on an accent background | White text on accent or charcoal full-bleed slides |
| Page numbers stale | Hardcoded | Derive from `len(builders)` after the list is built |
| Table sits on the footnote | Wrapping cell grew the row | Shorten text, widen the column, or raise the table |
| Deck is 4 MB+ | 300 DPI PNGs embedded raw | `downscale()` to about 1300 px |
| Slides blank after a restructure | Build error swallowed | Check the script exits 0, open the file |
